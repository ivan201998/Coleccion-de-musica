# Coleccion-de-musica
Generar la aplicación POO con Tests Unitarios que cumpla los siguientes 
requerimientos: Música

Se requiere tener Artistas, Álbumes y Canciones.

Los Artistas y los Álbumes son colecciones: cada uno agrupa una lista de 
otros elementos.

Todos los que sean colecciones deberían poder agregar un elemento a su 
lista.
Todos los que sean colecciones deberían poder consultar cuántos 
elementos tienen.

El Artista es una colección de Álbumes. Además, tiene un nombre, una 
cantidad de oyentes, y una descripción ("acerca de").

El Álbum es una colección de Canciones. Además, tiene un título y un 
año de lanzamiento.

La Canción tiene un título y una duración.
La Canción se puede reproducir (esto solo debería mostrar algún mensaje indicando qué canción está sonando).
